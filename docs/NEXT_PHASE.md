# Next Phase

Phase 12 v0.13 establishes both a transient-preserving hybrid and a real account-backed Provider A/B. The controlled result shows that Governor ROI can reduce calls, Token and latency while retaining the tested semantics; the hybrid preserves the tested A→B→A pulse at Passive's delivery count, but not more total exact intermediate states.

Recommended Phase 13 order:

1. Replace fixed three-frame reversal thresholds with calibrated multiscale salience features while keeping the current policy as a baseline.
2. Add an explicit pre-call cost estimator and distinguish continuation threshold, projected run budget and actual post-call usage in the contract.
3. Extend real A/B to multiple bounded visual tasks and held-out render variants without exposing expected labels.
4. Add a semantic event classifier over immutable observation events; keep it unable to authorize actions.
5. Compare model/provider variants only through separate explicit opt-in runs and record capability-probe provenance.
6. Measure local raster/signature CPU time and memory so delivery-byte savings are not mistaken for total-system savings.
7. Add timestamped synthetic audio and opt-in narration scheduling only after visual event retention is explicit.
8. Persist bounded timeline metadata with retention/deletion controls and no raw copyrighted frames by default.
9. Implement a separate MCP `2026-07-28` stateless adapter and conformance suite while retaining the legacy endpoint.
10. Reuse the contract in MSSP game/desktop experiments only through isolated, reversible and explicitly authorized machine tests.

Productization remains separate: authentication, rate limits, multi-tenant isolation, deterministic fonts, data retention policy, official SDK integration and independent security review.
